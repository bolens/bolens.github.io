# 404 customization contract

Season radios use `portfolio-scene-season`; moon radios use `portfolio-moon-phase`.
Both groups have named legends, visible section labels, and immediate polite status
announcements. They appear only on `.lost-page` with the relevant controller API.
External changes update checked values without moving focus or announcing a timer.

The season default does not alter weather/time/moon. Automatic moon clears only
the lunar override. A disabled checked custom radio is visible for an unmatched
external phase; valid presets and automatic remain operable.

Material composition: seasonal fallbacks beneath weather-specific material colors;
winter deciduous leaf visibility is final and excludes branches, snow, and evergreen
foliage. Seasonal flower petals disappear in autumn/winter while stalks remain.
No whole-object opacity or new transform owner is introduced.

Narrow viewports use the existing scrollable panel. Closing and returning focus,
normal-page controls, disabled-script art, and motion preferences keep their contracts.
